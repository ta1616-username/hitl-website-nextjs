# Infographics

The Case Studies tab expects three JPGs in this folder. Copy them from your
local `Documents/Human-In-The-Loop Solutions/Infographics/` folder into here,
keeping the filenames exactly as written below:

- `RLHF_Edge_Case_01_Linguistic_Constraints_page-0001.jpg`
- `RLHF_Edge_Case_02_AI_Tutoring_page-0001.jpg`
- `RLHF_Edge_Case_03_Empathy_Calibration_page-0001.jpg`

Once they are here, the tab will render thumbnails and the modal overlay
will show the full-size annotated image.

If you rename the files, update the `src` paths in `lib/homepage.jsx` to
match.
